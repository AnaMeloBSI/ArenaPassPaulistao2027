# ArenaPass — Paulistão 2027

<p align="center">
Sistema web de precificação dinâmica e gestão de ocupação de arenas desenvolvido para o Campeonato Paulista de Futebol 2027.
</p>

---

## Sobre o Projeto
Este projeto tem como objetivo otimizar a gestão da ocupação das arenas esportivas e modernizar a venda de ingressos no Paulistão 2027, ajustando os valores dos bilhetes de acordo com a demanda das partidas e oferecendo uma interface intuitiva, transparente e acessível tanto para torcedores quanto para gestores de clubes.

A interface atual (Versão 2) foi refinada a partir de uma Avaliação Heurística baseada nos princípios de usabilidade de Nielsen, corrigindo problemas de sobrecarga visual, perda de sessão, transparência na variação de preços e prevenção de erros administrativos.

---

## Funcionalidades

### Visão do Torcedor
- Visualização rápida das partidas e indicadores de demanda em tempo real (ex.: *Alta demanda*)
- Seleção simplificada de setores do estádio e quantidade de ingressos
- Trava visual de preço com cronômetro regressivo de 5 minutos (*Preço reservado*)
- Fluxo contínuo de compra com sessão ativa e cálculo automático do valor total

### Visão do Gestor
- Painel analítico com taxa de ocupação da arena, total de ingressos vendidos e gráfico de evolução
- Configuração de regras de ajuste por demanda com limite máximo de segurança (30%)
- Janela de confirmação preventiva antes de aplicar alterações nos preços
